# Story Director

ส่วนขยาย (extension) สำหรับ SillyTavern ที่คอยดูแลไม่ให้เนื้อเรื่องนิ่งจนน่าเบื่อ โดยมี "Story Director" (ปัญญาประดิษฐ์ที่ตัดสินใจแยกต่างหาก) คอยเปิด เดินหน้า หรือคลี่คลายปมเรื่อง (เธรด) อย่างต่อเนื่อง แทนการสุ่มเหตุการณ์ที่ไม่เกี่ยวข้องกัน พร้อมสมุดไดอารี่ของตัวละครที่เขียนขึ้นอย่างละเอียด ผูกโยงกับเธรดเดียวกัน

สร้างโดย Purryverse

## หลักการทำงาน

- **Director** เป็นการเรียกใช้งานปัญญาประดิษฐ์แยกต่างหากที่ทำงานเบื้องหลังหลังข้อความของตัวละครแต่ละครั้ง โดยพิจารณาบทสนทนาล่าสุดและสถานะของเธรดที่มีอยู่ แล้วตัดสินใจว่าจะเปิดเธรดใหม่ ดันเธรดเดิมให้คืบหน้า หรือดันเธรดขึ้นสู่จุดพีคแล้วปิดลง การประเมินระยะเวลาที่ผ่านไปในเรื่องก็เป็นส่วนหนึ่งของการตัดสินใจนี้เช่นกัน โดยไม่มีระบบข้ามเวลาแยกต่างหาก
- ระบบนี้ใช้การเรียก API แยกต่างหากเสมอ ไม่ใช่ทางเลือกเสริม เพื่อไม่ให้ผลลัพธ์ขึ้นอยู่กับว่าโมเดลหลักของแชทจะปฏิบัติตามคำสั่งที่แทรกเข้าไปหรือไม่ การทำงานเกิดขึ้นในช่วงเวลาระหว่างข้อความ จึงไม่เพิ่มเวลารอให้กับการสนทนาที่กำลังดำเนินอยู่
- **ไดอารี่** เขียนขึ้นจากมุมมองบุคคลที่หนึ่งของตัวละคร ความยาวหลายย่อหน้า เมื่อเธรดใดเธรดหนึ่งมีความคืบหน้าอย่างมีนัยสำคัญ พร้อมการไฮไลต์ประโยคสำคัญและปฏิทินภายในเรื่องของตัวเอง ในแชทกลุ่มไดอารี่จะผูกกับตัวละครที่เธรดนั้นเน้น และปิดการเขียนเป็นรายตัวได้

## v2.0.0 — อัปเดตใหญ่

- **ปักหมุด/บังคับปิดเธรด** และ **cooldown กันธีมซ้ำ** หลังปิดเธรด
- **มอบหมายเธรดให้ตัวละครเฉพาะ** ในแชทกลุ่ม พร้อมไดอารี่แยกตามตัวละครและปิดได้เป็นรายคน
- **กราฟ/ไทม์ไลน์อารมณ์** และ **ปฏิทินรายเดือน** ในแท็บไดอารี่
- **วันสำคัญที่ตั้งเอง** ให้ Director อ้างอิงตามปฏิทินในเรื่อง
- **ธีมสีหน้าไดอารี่** 5 แบบ และ **สติกเกอร์อารมณ์ของตัวเอง**
- **นำเข้าไดอารี่** จากไฟล์ .md/.txt ที่ระบบนี้ export ออกมา
- **สำรอง/กู้คืนข้อมูลเนื้อเรื่อง** (เธรด+ไดอารี่+ปฏิทิน) แยกจากไฟล์ตั้งค่า

## v2.1.0

- **ขีดฆ่า/ขีดเส้นใต้** ในเนื้อหาไดอารี่ นอกเหนือจากไฮไลต์เดิม
- **ปัดซ้าย-ขวาเพื่อเปลี่ยนหน้าไดอารี่** พร้อมเอฟเฟกต์หน้าพลิก (มีปุ่มลูกศรสำหรับจอที่ปัดไม่ได้ด้วย)
- **ปักหมุด/พับมุมหน้าโปรด** พร้อมตัวกรองดูเฉพาะหน้าโปรด

## v2.2.0

- เพิ่ม markup ตัวที่ 4 ในไดอารี่: **`` `พูดไม่ตรงใจ` ``** (แบ็กทิกคู่) เส้นใต้จุดสีชมพู ควบคู่กับ 3 แบบเดิม (ไฮไลต์/ขีดฆ่า/ขีดเส้นใต้)

## v2.3.0

- **คลังเหตุการณ์ล่วงหน้า** — เขียนปมเรื่องดักไว้ได้ Director เลือกใช้ก่อนคิดเองเสมอถ้ายังมีเหลือ
- **Time Skip** — Director ข้ามเวลาไป ชม./วัน/สัปดาห์ ได้เอง พร้อมเล่าสรุปสถานะเธรดที่ค้างอยู่แทรกเข้าไปในฉากอย่างเป็นธรรมชาติ
- **Follow-up ต่อเนื่อง** — เธรดที่ดันคืบมีโอกาสผูกคิวบังคับให้ Director ต้องกลับมาต่อเธรดเดิมในอีกไม่กี่ข้อความ
- **เชื่อมเธรดเข้าด้วยกัน** — ทำเครื่องหมายเธรดที่เกี่ยวโยงกัน ให้ Director เห็นภาพรวมตอนตัดสินใจ

## v2.8.0

- **คู่มือเริ่มต้นใช้งานในตัว** — เพิ่มปุ่ม "คู่มือเริ่มต้น" ไว้ด้านบนของป็อปอัพตั้งค่า กดแล้วเปิดเป็นแผงลอยแยกต่างหาก ย่อ/ขยายได้ ลากย้ายตำแหน่งได้ และปรับขนาดได้ (ลากมุมขวาล่าง) ไม่ต้องออกไปเปิดไฟล์แยกอีกต่อไป (เนื้อหาเดียวกับ GUIDE.md)

## v2.7.0

- **ความลับของตัวละคร (Secrets)** — ตั้งความลับของตัวละคร/NPC ไว้ล่วงหน้าในแท็บ "ตั้งค่า" (เขียนเนื้อหาเองหรือเว้นว่างให้ Director แต่งเองตอนเริ่มใช้) Director จะค่อยๆ ปล่อยเบาะแสผ่านเหตุการณ์/ไดอารี่ทีละนิด แล้วเลือกจังหวะเฉลยเองเมื่อสะสมเบาะแสมากพอ ดูความลับที่กำลังดำเนินอยู่และเฉลยเองได้ทันทีในแท็บ "เธรด" ปิด/เปิดได้
- **Callback อดีต** — Director จะหยิบรายละเอียดเล็กๆ จากเธรดที่ปิดไปนานแล้วหรือไดอารี่เก่ามากๆ (ที่ผู้เล่นอาจลืมไปแล้ว) กลับมาโผล่ใหม่แบบไม่ทันตั้งตัวเป็นครั้งคราว ปรับได้ว่าจะนับว่า "เก่า" เมื่อผ่านไปกี่ข้อความ ปิด/เปิดได้ในแท็บ "ตั้งค่า"
- **โครงเรื่องระยะยาวแบบซีซั่น (Story Arcs)** — Director วางแผน "อาร์ค" ใหญ่ล่วงหน้า (ตั้งชื่ออาร์ค กำหนดความยาวเป็นจำนวนเหตุการณ์ และจุดไคลแมกซ์ที่วางแผนไว้) แล้วพยายามดันเหตุการณ์ต่างๆ ให้เข้ากับทิศทางของอาร์คนั้นจนถึงจุดจบ ดูความคืบหน้าของอาร์คปัจจุบันได้ในแท็บ "เธรด" ปรับความยาวอาร์คขั้นต่ำ/สูงสุดได้ในแท็บ "ตั้งค่า"
- **"ความเดิมตอนที่แล้ว" อัตโนมัติ** — ถ้าห่างหายไปนาน (นับเวลาจริง ปรับได้ว่ากี่ชั่วโมง) ระบบจะแทรกให้ตัวละครพูดถึงหรือให้ narrator สรุปสั้นๆ ว่าเธรดไหนค้างอะไรอยู่ก่อนดำเนินฉากถัดไป ทำครั้งเดียวตอนกลับมาแต่ละรอบ ไม่ต้องเรียก API เพิ่ม ปิด/เปิดได้ในแท็บ "ตั้งค่า"

## v2.6.0

- **บุคลิก Director** — เลือกโทนให้ Director ใช้ตัดสินใจแต่ละครั้ง: สมดุล, ดราม่าเข้ม, ตลก/เบาสมอง, Slow burn, สายทวิสต์ หรือสุ่มสลับเองทุกครั้ง (แท็บตั้งค่า)
- **ตัวช่วยกันเธรดจำเจ** — ระบบสังเกตว่าเธรดใหม่ๆ ล่าสุดใช้อารมณ์/ธีมเดิมซ้ำกันบ่อยเกินไปไหม แล้วเตือน Director ให้เปลี่ยนไปทางอื่นตอนเปิดเธรดใหม่ครั้งถัดไป ปิด/เปิดได้ในแท็บตั้งค่า
- **เหตุการณ์ที่มี NPC เกี่ยวข้อง** — Director ดึงตัวละครสมทบ (NPC) เข้ามาเกี่ยวข้องกับเหตุการณ์ได้ (ไม่บังคับทุกครั้ง ปรับความถี่ได้: นานๆ ครั้ง / บ่อยๆ / เกือบทุกครั้ง) มีทำเนียบ NPC ให้ผู้เล่นเพิ่มชื่อ/บทบาทที่อยากใช้ไว้ล่วงหน้าได้ หรือปล่อยให้ Director แต่ง NPC ใหม่เองก็ได้ ปิด/เปิดได้ในแท็บตั้งค่า
- **แผนที่ความสัมพันธ์ระหว่าง NPC** — ในแท็บเธรด แสดง NPC ทุกคนที่เคยปรากฏในเรื่องเป็นจุดบนแผนภาพ พร้อมเส้นเชื่อมสีเขียว/แดงบอกว่าความสัมพันธ์ระหว่าง NPC สองคนนั้นดีหรือตึงเครียด (แยกจากค่าความผูกพันกับผู้เล่นที่มีอยู่เดิม)

## v2.5.0

- **แท็บที่ 5** — แยก "เธรด/เหตุการณ์" เดิมออกเป็นสองแท็บ: **ตั้งค่า** (ไอคอนฟันเฟือง — ธีม/ความถี่/ความรุนแรง/Time Skip/Follow-up/คลังเหตุการณ์/Prompt Preview) กับ **เธรด** (สถานะเธรดสด + แผนที่เธรด + แผนที่ความผูกพัน) ตอนนี้มี 5 แท็บ: ทั่วไป, ตั้งค่า, เธรด, ไดอารี่, ประวัติ
- **ไอคอนสภาพอากาศบนหน้าไดอารี่** — อ่านข้อความสภาพอากาศที่ตัวละครเขียนไว้แล้วเลือกไอคอนที่ใกล้เคียงให้อัตโนมัติ ทั้งในหน้าอ่านและรายการ ปิด/เปิดได้ในแท็บไดอารี่
- **ระบบความผูกพัน (Bond)** — ค่า 0-100 ต่อตัวละคร ให้ Director ประเมินหลังทุกเหตุการณ์ว่ากระทบความผูกพันกับผู้เล่นแค่ไหน มีกราฟเส้นย้อนหลังในแท็บไดอารี่ และแผนที่ภาพรวมของทุกตัวละครในแท็บเธรด (สำหรับแชทกลุ่ม — แสดงความผูกพันแต่ละตัวละครกับผู้เล่น ยังไม่ใช่ความสัมพันธ์ระหว่างตัวละครด้วยกันเอง) ปิด/เปิดได้ในแท็บไดอารี่
- **จดหมายถึงอนาคต** — เขียนจดหมายถึงตัวละคร ตั้งวันที่ในปฏิทินของเรื่องที่อยากให้จดหมายมาถึง พอปฏิทินในเรื่องเดินถึงวันนั้น ระบบจะแทรกให้ตัวละครอ่านและตอบสนองในฉากถัดไปทันที ไม่ต้องรอ Director ตัดสินใจ
- **ค้นหาไดอารี่ด้วยคำ** — ช่องค้นหาข้อความในเนื้อหาไดอารี่ ในแท็บไดอารี่
- **อัปโหลดเสียงแจ้งเตือนเอง** — นอกจาก 6 แบบสังเคราะห์เดิม อัปโหลดไฟล์เสียงของตัวเองได้สูงสุด 5 เสียง (ไม่เกิน 300KB/ไฟล์) เลือกใช้ได้จากช่อง "เลือกเสียง" เหมือนเดิม
- **จำกัดไดอารี่ไว้ที่ 300 รายการ/แชท และรองรับการค้นหา/สำรองข้อมูลค่าความผูกพันกับจดหมายในไฟล์ backup**

## v2.4.0

- **แผนที่เธรด** — ในแท็บสถานะเธรด แสดงเธรดที่กำลังดำเนินอยู่เป็นจุดบนแผนภาพ ขนาดจุดสื่อความเข้มข้นทางอารมณ์ เส้นเชื่อมสื่อเธรดที่โยงกัน แตะจุดเพื่อเลื่อนไปดูเธรดนั้นในรายการด้านล่าง
- **ปรับปรุงประสิทธิภาพไดอารี่** — จำกัดจำนวนบันทึกไดอารี่สูงสุดไว้ที่ 300 รายการต่อแชท (ตัดรายการเก่าที่ไม่ได้ปักดาวก่อน กันไม่ให้แชทที่เล่นยาวมากๆ โตไม่มีที่สิ้นสุด), รายการไดอารี่โหลดทีละ 40 รายการพร้อมปุ่ม "โหลดเพิ่มเติม" แทนที่จะ render ทั้งหมดพร้อมกัน, และแคชรายชื่อตัวละครในตัวกรองไดอารี่ไม่ให้คำนวณซ้ำทุกครั้งที่เปิดหน้าต่างตั้งค่า

## วิธีติดตั้ง

1. เปิด SillyTavern แล้วไปที่แท็บ Extensions
2. กด Install extension แล้ววางลิงก์ที่เก็บซอร์สของคุณ หรือคัดลอกโฟลเดอร์นี้ไปที่ `.../SillyTavern/public/scripts/extensions/third-party/story-director/`
3. รีสตาร์ต SillyTavern แล้วโหลดหน้าเว็บใหม่

## ตั้งค่าเริ่มต้น (จำเป็น)

Story Director ต้องมี Connection Profile (ฟีเจอร์ในตัวของ SillyTavern) ที่ตั้งค่าไว้แล้วก่อนถึงจะทำงานได้:

1. เปิดเมนู Story Director จากไอคอนรูปอุ้งเท้าในเมนูส่วนขยาย
2. แท็บ "ทั่วไป" เลือกโปรไฟล์ API ในหัวข้อ "API สำหรับ Director" แล้วกด "ทดสอบ" เพื่อยืนยันการเชื่อมต่อ
3. แท็บ "ตั้งค่า" เลือกธีมที่ต้องการ และปรับความถี่กับความรุนแรงตามความเหมาะสม
4. แท็บ "ไดอารี่" เปิดใช้งานหากต้องการ
5. กดบันทึก

จากนั้น Director จะตัดสินใจเองหลังข้อความของตัวละครแต่ละครั้งตามความถี่ที่ตั้งไว้ หากต้องการให้ตัดสินใจทันทีโดยไม่ต้องรอ สามารถกดปุ่ม "เร่งให้ Director ตัดสินใจในข้อความถัดไป" ในแท็บทั่วไปได้
