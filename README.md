# Story Director

ส่วนขยาย (extension) สำหรับ SillyTavern ที่คอยแทรกเหตุการณ์เข้ามาในเนื้อเรื่องระหว่างแชท ให้เรื่องมีจังหวะ มีสีสัน ไม่นิ่งจนน่าเบื่อ โดยไม่ต้องคอยเขียนกำกับเองทุกครั้ง

สร้างโดย **Purryverse**

## วิธีติดตั้ง

1. เปิด SillyTavern แล้วไปที่แท็บ **Extensions** (ไอคอนรูปลูกบาศก์ 🧩 บนแถบเมนูด้านบน)
2. กดปุ่ม **Install extension**
3. ในช่อง "Enter the Git URL of the extension to install" ให้ใส่ลิงก์นี้:

   ```
   https://github.com/poeuliyn/Story-Director.git
   ```

4. กด **Install for all users** (หรือ **Install just for me** ถ้าอยากติดตั้งเฉพาะบัญชีตัวเอง)
5. รอจนติดตั้งเสร็จ แล้ว **รีสตาร์ต SillyTavern** และรีเฟรชหน้าเว็บอีกครั้ง

ติดตั้งเสร็จแล้วจะมีเมนู **Story Director** โผล่มาในเมนู Extensions (ไอคอนไม้กายสิทธิ์ 🪄 ด้านบนหน้าแชท) — กดตรงนั้นเพื่อเปิดหน้าตั้งค่าได้ทุกเมื่อ

## มีอะไรให้ใช้บ้าง

หน้าตั้งค่าแบ่งเป็น 5 หมวดหลัก:

- **⚙️ ทั่วไป** — เปิด/ปิดระบบทั้งหมด, เลือกวิธีที่เหตุการณ์จะปรากฏในเรื่อง (แนบเนียนกลืนไปกับคำบรรยาย / แยกเป็นผู้บรรยายชัดเจน / ให้โมเดลเลือกเอง), และเสียงแจ้งเตือน
- **🎲 เหตุการณ์** — หัวใจหลักของส่วนขยายนี้ ตั้งได้ว่าเหตุการณ์จะเกิดถี่แค่ไหน (ทุก N ข้อความ, สุ่ม %, หรือปล่อยให้ค่อยๆ สะสมความตึงเครียดแล้วมีโอกาสเกิดมากขึ้นเมื่อเรื่องนิ่งนานๆ), ความรุนแรงของเหตุการณ์, เหตุการณ์ต่อเนื่อง (เรื่องเดิมถูกหยิบมาสานต่อ), ฟีเจอร์ข้ามเวลา (time skip), และเลือกได้ว่าจะให้เขียนเหตุการณ์เองไว้ล่วงหน้า (Fixed Pool) หรือให้ AI แต่งสดจากธีมที่เลือก
- **📔 ไดอารี่** — ให้ตัวละครเขียนไดอารี่ส่วนตัวขึ้นเองเป็นระยะ พร้อมระบบปลดล็อกเป็นสมุดให้ย้อนอ่านได้
- **📊 สถิติ/ประวัติ** — ดูสถิติภาพรวมและประวัติเหตุการณ์ทั้งหมดที่เคยเกิดขึ้นในแชทนี้ย้อนหลังได้
- **📁 นำเข้า/ส่งออก** — บันทึกชุดการตั้งค่าเป็นไฟล์ .json ไว้สำรอง หรือนำไปใช้กับตัวละคร/แชทอื่นได้ทันที

ทุกการตั้งค่าเป็นแบบ**แยกตามแชท** — ปรับแชทหนึ่งแล้วจะไม่ไปกระทบแชทอื่น

## วิธีใช้งานเบื้องต้น

1. เปิดเมนู Story Director จากไอคอนไม้กายสิทธิ์ในหน้าแชท
2. ไปที่แท็บ **ทั่วไป** ติ๊กเปิดใช้งานกับแชทนี้ (เปิดเป็นค่าเริ่มต้นอยู่แล้ว)
3. ไปที่แท็บ **เหตุการณ์** เลือกโหมดแหล่งที่มาของเหตุการณ์:
   - **Fixed Pool** — เขียนเหตุการณ์ของตัวเองไว้ล่วงหน้าในช่องข้อความ บรรทัดละ 1 รายการ (หัวข้อสั้น / รายละเอียดเต็ม / แท็กและน้ำหนักถ้าต้องการ) ระบบจะสุ่มหยิบมาใช้
   - **AI สร้างจากธีม** — เลือกแท็กธีมที่สนใจ แล้วปล่อยให้โมเดลแต่งเหตุการณ์สดขึ้นมาเองทุกครั้ง
4. ปรับความถี่และความรุนแรงของเหตุการณ์ตามชอบ แล้วกด **บันทึก**
5. คุยแชทตามปกติ — เหตุการณ์จะแทรกเข้ามาเองตามจังหวะที่ตั้งไว้ พร้อมเสียงแจ้งเตือน (ถ้าเปิดไว้)
6. อยากให้เหตุการณ์เกิดทันทีโดยไม่ต้องรอ ก็กดปุ่ม **"สั่งเหตุการณ์ในข้อความถัดไปทันที"** ในแท็บทั่วไปได้เลย มีผลทันทีไม่ต้องกดบันทึก

ลองเปิดดูแต่ละแท็บเพิ่มเติมได้ ทุกช่องตั้งค่าจะมีคำอธิบายกำกับไว้ใต้ตัวเลือกอยู่แล้วว่าใช้ทำอะไร
