# Story Director v3

ส่วนขยาย (extension) สำหรับ SillyTavern ที่คอยดูแลไม่ให้เนื้อเรื่องนิ่งจนน่าเบื่อ โดยมี "Story Director" (AI ตัดสินใจแยกต่างหาก) คอยเปิด/ดัน/ปิดปมเรื่อง (เธรด) แทนการสุ่มเหตุการณ์ลอยๆ แบบเดิม พร้อมสมุดไดอารี่ตัวละครแบบเขียนยาว ผูกกับเธรดเดียวกัน

สร้างโดย **Purryverse**

## มีอะไรเปลี่ยนจากเวอร์ชันก่อน

- **ตัดระบบ Fixed Pool / AI-mode / Time Skip เดิมทิ้ง** แทนที่ด้วย Director ตัวเดียวที่ตัดสินใจทุกอย่าง (เปิดเธรดใหม่ / ดันเธรดคืบ / ดันถึงจุดพีคแล้วปิด) — ไม่มีการข้ามเวลาแยกต่างหากอีกต่อไป Director เป็นคนประเมินเวลาที่ผ่านไปเองในทุกการตัดสินใจ
- **ใช้ API แยกเสมอ ไม่ใช่ตัวเลือกเสริม** — Director และไดอารี่ไม่พึ่งพาให้โมเดลหลักของแชท "ทำตาม" คำสั่งแฝงอีกต่อไป (ต้นเหตุหลักของปัญหา "ตั้งค่าไว้แต่ไม่มีอะไรเกิดขึ้น" ในเวอร์ชันก่อน) ทำงานเบื้องหลังหลังข้อความของตัวละครแต่ละครั้ง ไม่เพิ่มเวลารอตอนแชท
- **ไดอารี่เขียนยาว 4-8 ย่อหน้า ผูกกับเธรด** ไม่ใช่สุ่มแยกขาดแบบเดิม เขียนเมื่อเธรดมีความคืบหน้าจริง พร้อมไฮไลต์ประโยคสำคัญและปฏิทินในเรื่องของตัวเอง

## วิธีติดตั้ง

1. เปิด SillyTavern แล้วไปที่แท็บ **Extensions** (ไอคอนรูปลูกบาศก์ 🧩)
2. กด **Install extension** แล้ววางลิงก์ repo ของคุณ หรือคัดลอกโฟลเดอร์นี้ไปที่ `.../SillyTavern/public/scripts/extensions/third-party/story-director/`
3. รีสตาร์ต SillyTavern แล้ว hard refresh หน้าเว็บ

## ตั้งค่าเริ่มต้น (สำคัญ)

Story Director v3 **ต้องมี Connection Profile** (ฟีเจอร์ในตัวของ SillyTavern 1.12.6+) ก่อนถึงจะทำงานได้:

1. เปิดเมนู Story Director จากไอคอนไม้กายสิทธิ์ 🪄
2. แท็บ **⚙️ ทั่วไป** → เลือกโปรไฟล์ API ในช่อง "API สำหรับ Director" → กด **ทดสอบ** เพื่อยืนยันว่าเชื่อมต่อได้
3. แท็บ **🧵 เธรด/เหตุการณ์** → เลือกธีมที่ต้องการ ปรับความถี่/ความรุนแรงตามชอบ
4. แท็บ **📔 ไดอารี่** → ติ๊กเปิดใช้งานถ้าต้องการ
5. กด **บันทึก**

จากนั้นคุยแชทตามปกติ Director จะตัดสินใจเองหลังข้อความของตัวละครแต่ละครั้งตามความถี่ที่ตั้งไว้ อยากให้ตัดสินใจทันทีโดยไม่ต้องรอ กดปุ่ม **"เร่งให้ Director ตัดสินใจในข้อความถัดไป"** ในแท็บทั่วไปได้เลย
